# Shell completions

Completion scripts are generated by the installed binary, so they match its
command flags and version.

## Generate

```bash
scrobbler completion zsh
scrobbler completion bash
scrobbler completion fish
scrobbler completion powershell
```

`pwsh` is accepted as an alias for `powershell`.

## Install per user

```text
scrobbler completion install
scrobbler completion install zsh
scrobbler completion install bash
scrobbler completion install fish
scrobbler completion install powershell
```

Without a shell argument, the current shell is detected. The manager uses
per-user locations: `~/.zfunc/_scrobbler` for zsh,
`~/.local/share/bash-completion/completions/scrobbler` for bash,
`~/.config/fish/completions/scrobbler.fish` for fish, and a per-user
PowerShell completion directory. PowerShell also receives a profile import;
zsh receives the necessary `fpath`/`compinit` line. Existing profiles are
backed up once and marker lines are not duplicated.

The command reports `installed`, `already installed`, `updated`, or
`manual configuration required`. It does not write root-owned files. A shell
or profile reload may be required after installation.

The same workflow is available in **Settings → Tools → Install Completions**.
The TUI's shell selector and status are driven by the same manager as the CLI.
